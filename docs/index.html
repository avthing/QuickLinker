QuickLinker

自動偵測網頁中的關鍵資訊，一鍵在多個網站同時搜尋，並即時告訴你哪些連結真的存在。

加到 Chrome — 免費安裝 在 GitHub 上查看

不需註冊帳號，所有資料只存在你的瀏覽器裡。

核心特色

把「複製、切換分頁、貼上、搜尋」這串動作壓縮成一次點擊。

🎯

智慧內容偵測

自動從網頁中提取編號、代碼、ID 等關鍵資訊，不用手動複製貼上。

🔍

即時多站搜尋

一次在多個網站同時查詢，並即時標示每個連結是否真的存在。

🖱️

右鍵選單整合

選取畫面上任何一段文字，直接從右鍵選單發動搜尋。

⚙️

高度可客製化

自訂搜尋網站、網址樣板與掃描模式，完全依你的工作流程調整。

🔒

隱私優先

所有設定只存在本機，不上傳任何資料，原始碼公開可審查。

⚡

輕量不卡頓

以 Manifest V3 打造，背景常駐資源極低，不拖慢瀏覽速度。

使用方式

安裝完就能用，不需要任何設定。

1

自動偵測

開啟支援的網站時，QuickLinker 會自動抓出關鍵資訊並顯示浮動按鈕。

2

展開查看

點擊按鈕展開所有可搜尋的網站，並即時檢查每個連結的可用性。

3

一鍵跳轉

點任一網站即可直接前往搜尋結果，重複的分頁會自動去重。

適用場景

只要你的工作需要在多個網站間反覆查同一個關鍵字，它就派得上用場。

📚

開發者

在 GitHub、Stack Overflow 與各家文件之間，快速追同一則錯誤訊息或 Issue。

🛒

電商比價

同一件商品在多個購物網站同時查，一眼看出哪裡有貨、哪裡最便宜。

📖

研究人員

用同一組關鍵字橫掃多個學術資料庫與論文網站，不必逐站重打。

🎬

內容愛好者

在各個平台之間搜尋影片、音樂或書籍，先確認有沒有再點進去。
