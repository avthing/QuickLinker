## 繁體中文

QuickLinker - 智慧連結聚合與快速搜尋工具

透過智慧內容偵測與即時多站搜尋整合，大幅提升您的搜尋效率。QuickLinker 能自動提取網頁中的關鍵資訊，讓您即時在多個平台搜尋相關內容。

🎯 核心特色

• 智慧內容偵測：自動提取網頁中的 ID、編號、代碼等關鍵資訊
• 即時多站搜尋：一鍵在多個網站同時搜尋，即時顯示連結可用性
• 右鍵選單整合：選取任何文字即可快速搜尋
• 高度可客製化：自訂搜尋網站、掃描模式與分頁行為
• 多語言介面：支援繁體中文、簡體中文、英文、日文、韓文，可自動跟隨瀏覽器或於設定頁手動指定
• 現代化介面：漸層設計與流暢動畫，並支援深色主題
• 隱私優先：所有設定儲存於本機，不收集任何個人資訊

✨ 使用方式

1. 瀏覽任何網站，QuickLinker 會自動偵測頁面中的關鍵資訊
2. 右下角出現浮動按鈕
3. 點擊展開，查看所有已設定的搜尋網站
4. 以顏色標示連結狀態：
   🟢 綠色邊框：連結確認可用
   🔴 紅色邊框：連結確認不存在（僅「最佳結果」模式顯示）
   🟡 黃色邊框：檢查中
   ※ 無法確認的網址不會建立按鈕，避免顯示誤導性的結果
5. 點擊任一按鈕即可跳轉；若該關鍵字已有開啟的分頁，會自動聚焦而非重複開啟

🎨 進階功能

• 可拖曳浮動按鈕，位置自動記憶（各網站獨立）
• 兩種掃描模式：最佳結果（最快）或完整掃描（顯示所有可用結果）
• 搜尋結果快取（30 分鐘），可於設定頁關閉
• 排除目前網站：瀏覽已設定的站台時，不再顯示連回自身的結果
• 最近搜尋紀錄，一鍵重新搜尋
• 分頁管理：可選擇搜尋後是否關閉原始分頁
• 匯入／匯出設定，方便備份與轉移
• 自訂搜尋網址，支援 {} 佔位符與 {lower}、{upper}、{nodash}、{dmm} 具名 token

🔒 隱私與安全

✅ 所有設定僅儲存於您的瀏覽器本機
✅ 不收集任何個人資訊，不會將任何資料回傳給開發者
✅ 沒有任何中介伺服器或分析追蹤
ℹ️ 為檢查連結可用性，擴充功能會直接向「您自行設定的網站」發送請求。這些請求僅用於判斷連結是否存在，不會經過開發者的伺服器
✅ 原始碼公開於 GitHub，歡迎審查

⚠️ 使用前提

首次開啟時需確認您已達法定年齡，且在您所在地區使用所設定的內容為合法。搜尋目標網站完全由使用者自行設定，本擴充功能不預設或推薦任何特定內容。

適合開發者、研究人員、購物比價者，以及任何需要頻繁跨網站搜尋的使用者。

💡 使用場景範例

• 開發者：在 GitHub、Stack Overflow、文件網站之間快速查找 Issue 編號
• 電商比價：在 Amazon、eBay 等購物網站之間比較同一件商品
• 研究人員：以文獻編號在多個學術資料庫中搜尋論文
• 一般使用者：以同一組關鍵字快速查詢多個搜尋引擎

用 ❤️ 為提升生產力而製作

## English

QuickLinker - Smart Link Aggregator & Quick Search Tool

Boost your search efficiency with intelligent content detection and instant multi-site search integration. QuickLinker automatically extracts key information from web pages and lets you search across multiple platforms in real time.

🎯 KEY FEATURES

• Smart Content Detection: Automatically extract IDs, codes, and keywords from web pages
• Real-Time Multi-Site Search: Search multiple sites at once with live link availability checking
• Right-Click Menu Integration: Quick search for any selected text
• Highly Customizable: Configure your own search sites, scan modes, and tab behavior
• Multilingual UI: Traditional Chinese, Simplified Chinese, English, Japanese, and Korean — follows your browser automatically, or pick one manually in settings
• Modern UI: Gradient design with smooth animations and dark theme support
• Privacy First: All settings stored locally, no personal data collected

✨ HOW IT WORKS

1. Visit any website and QuickLinker automatically detects relevant content
2. A floating button appears in the bottom-right corner
3. Click to expand and see all your configured search sites
4. Color-coded status indicators:
   🟢 Green border: Link confirmed available
   🔴 Red border: Link confirmed missing (shown in Best Match mode only)
   🟡 Yellow border: Checking
   Note: URLs that cannot be confirmed produce no button at all, so you never see a misleading result
5. Click any button to jump straight there. If a tab for that keyword is already open, it is focused instead of duplicated

🎨 ADDITIONAL FEATURES

• Draggable floating button with per-site position memory
• Two scan modes: Best Match (fastest) or Full Scan (shows every available result)
• Search result cache (30 minutes), can be disabled in settings
• Exclude current site: no more results linking back to the page you are already on
• Recent search history with one-click re-search
• Tab management: optionally close the original tab after searching
• Import/Export settings for backup and migration
• Custom search URLs supporting the {} placeholder plus the {lower}, {upper}, {nodash} and {dmm} named tokens

🔒 PRIVACY & SECURITY

✅ All settings stored locally in your own browser
✅ No personal data collected and nothing is ever sent back to the developer
✅ No intermediary servers and no analytics or tracking
ℹ️ To check link availability, the extension sends requests directly to the sites YOU configure. These requests only determine whether a link exists, and never pass through any developer-controlled server
✅ Source code is public on GitHub and open to review

⚠️ BEFORE YOU START

On first launch you must confirm that you are of legal age and that accessing the content you configure is lawful in your region. All search destinations are defined entirely by you — this extension does not preset or recommend any particular content.

Perfect for developers, researchers, shoppers, and anyone who frequently searches across multiple websites.

💡 EXAMPLE USE CASES

• Developers: Look up issue numbers across GitHub, Stack Overflow, and documentation sites
• E-commerce: Compare the same product across Amazon, eBay, and other stores
• Researchers: Search paper identifiers across multiple academic databases
• General users: Run the same query across several search engines at once
